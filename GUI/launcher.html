🌐 Remote access / Acceso remoto

No login from here: without a proxy with authentication in front, anyone on the network can control this PC. / Sin login desde aquí: sin un proxy con autenticación delante, cualquiera de la red puede controlar este PC.
This PC never asks for the password; other devices always do. Changes apply after restarting the launcher and the trainer. / Este PC nunca pide contraseña; los demás equipos siempre. Los cambios se aplican al reiniciar el lanzador y el entrenador.
Plain HTTP: for your home network only. To connect from the Internet use Tailscale or an SSH tunnel, never an open port. / HTTP sin cifrar: solo para la red de casa. Para entrar desde Internet usa Tailscale o un túnel SSH, nunca un puerto abierto.
